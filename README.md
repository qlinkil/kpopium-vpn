# Kpopium VPN

VPN-клиент для Windows 10 и 11 (64 бита) с тремя ядрами на выбор: Xray, sing-box и mihomo. Подписки, маршрутизация как в v2rayN, TUN, системный прокси, kill switch, монитор соединений и Clash-профили.

Здесь лежат только готовые сборки. Исходного кода в репозитории нет.

## Установка

1. Скачай `kpopium-vpn.exe` из раздела Releases и положи в постоянную папку, например `C:\Kpopium`.
2. Запусти и подтверди запрос прав администратора. Если появится окно SmartScreen, нажми «Подробнее», затем «Выполнить в любом случае»: у программы нет платной цифровой подписи.
3. При первом запуске программа сама скачает ядра и геобазы с их официальных страниц на GitHub.
4. На странице «Узлы» вставь ссылку на свою подписку.

## Обновление

В программе: Настройки → Обновление программы → Проверить. Настройки и подписки при обновлении сохраняются.

## Проверка файла

Контрольная сумма SHA-256 лежит рядом с программой в файле `kpopium-vpn.exe.sha256sum`. Программа сверяет её сама при обновлении.
